This page edits token defaults and per-repository token rules in the rules file, and reusable presets in the preset files — nothing else. Sources and token definitions come from the YAML configuration, which is edited by hand — this page never writes it. It never displays or changes values from the local env file and never writes provider secrets. Inventory refresh makes read-only provider requests. Pushing values is always a CLI action (apply), which prints the fresh plan and requires confirmation (or --yes in noninteractive use).

Presets

Reusable templates stored in the preset files . A token preset stamps scope fields into a token's rules-file overrides; a repository preset stamps token rules onto a repository's rules-file entry. Editing a preset afterwards does not re-apply it.

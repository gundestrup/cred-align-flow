This page edits per-repository token rules in the rules file only. Sources, tokens, and their default rules come from the YAML configuration, which is edited by hand — this page never writes it. It never displays or changes values from the local env file and never writes provider secrets. Inventory refresh makes read-only provider requests. Pushing values is always a CLI action (apply), which prints the fresh plan and requires confirmation (or --yes in noninteractive use).
